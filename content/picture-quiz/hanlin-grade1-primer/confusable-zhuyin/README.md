# 看圖選注音：易混注音候選詞

這個資料夾是「看圖選注音」題目的內容素材清單，**尚未匯入正式題組，也沒有附圖片**。先挑選單一物件、容易由照片或插圖辨識的詞，供日後由使用者或 agent 準備圖片並建立題目。

## 範圍

- 教材脈絡：翰林版國語文一年級首冊。
- 目前練習重點：`ㄓ／ㄗ`、`ㄔ／ㄘ`、`ㄕ／ㄙ`、`ㄥ／ㄣ`、`ㄛ／ㄡ`。
- 清單同時包含少量課文已核對的詞與「看圖辨識較清楚」的練習延伸詞；兩者在 `candidates.json` 內有標記，避免誤當成完整課文詞表。

## 使用方式

1. 先替候選詞準備一張不含文字、主體清楚的照片或插圖。
2. 檢查照片不會讓孩子答成其他合理名詞（例如把紙答成書）。
3. 由題組管理頁或匯入包建立正式題目，選項與正解均由成人預先指定；系統不自動產生錯誤選項。
4. 圖片上傳後，將 `imageStatus` 與人工覆核結果更新在題組資料中。

## 已找到的圖片來源

[`image-sources.json`](image-sources.json) 為十個候選詞指定了同一套 OpenMoji 彩色 SVG 預覽。這一套不是實際課本插圖，但線條、色彩與背景處理一致，適合作為第一輪的「看圖辨識」測試素材。

- 圖檔尚未下載或匯入 Firebase；清單只保存可驗證的來源網址與授權資料。
- 使用 OpenMoji 時，正式頁面或素材說明須保留署名：「All emojis designed by OpenMoji – License: CC BY-SA 4.0」。
- 若希望更接近本專案的童書感，建議以同一份 `imagePrompt` 重新繪製一整組原創插圖；不要混用網路上不同畫風或來源不明的課本掃描圖。

## 資料來源與界線

- 課次與教材書目請看 [`docs/textbook-catalogs/hanlin-grade1-mandarin-primer/README.md`](../../../../../docs/textbook-catalogs/hanlin-grade1-mandarin-primer/README.md)。
- 「課文參照」只表示此詞或相關詞可在該課脈絡中使用，不代表逐字轉錄全文，也不構成完整教材內容。
- 練習延伸詞是為了把五組易混音都做成具體圖片題；可依孩子的經驗再刪減或替換。
