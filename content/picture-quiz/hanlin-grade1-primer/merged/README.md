# 注音練習：翰林首冊（合併題組）

2026-11-08 依使用者要求，把「易混注音」（10 題）和「課文詞語」（7 題）合併成一個題組，共 17 題。要出哪幾題，由大人在題組管理頁勾選。

- `picture-set.json`：題組代號 `hanlin-g1-primer`；測試版內建同一份（`preview/picture-sets/hanlin-g1-primer.json`）。
- 每題有 `lesson`（畫面上顯示的課次）和 `lessonNote`（依據）。課次由 Codex 依公開課程計畫與第三課詞卡核對：
  - 詞本身出現在課文：標課次，例如「第三課〈來數數〉」。
  - 由課文改寫、縮略，或課本沒有的詞：標「延伸練習」，能對應到某課的加註課次，例如「延伸練習（第三課〈來數數〉）」。
- `previousIds` 與 `set.replaces`：匯入時把舊題組的答題紀錄和「出題」勾選接到新題目，再從裝置移除兩個舊題組。
- 圖片和選項的原始素材仍在 `../confusable-zhuyin/` 與 `../lesson-words/`。
