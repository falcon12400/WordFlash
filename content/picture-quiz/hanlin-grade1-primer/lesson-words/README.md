# 注音練習：翰林首冊課文詞語

使用者在 2026-11-08 指定的 7 個詞：老師、收起來、籃子、數一數、一張圖、三隻、大樹。

- `picture-set.json`：匯入包，題組代號 `hanlin-g1-lesson-words`。測試版網站內建同一份檔案（`preview/picture-sets/hanlin-g1-lesson-words.json`）。
- `original-art/`：7 張自繪 SVG，照 OpenMoji 的粗線條風格畫，沒有版權問題。
- 每題 4 個選項：正解，加上 Claude 擬的 3 個錯誤選項（換易混的聲母、韻母或聲調）。
- 待確認：
  - 「一」的標法：目前標本調 ㄧ（數一數、一張圖）。如果課本標變調（例如一張的 ㄧˋ），要改正解；錯誤選項都沒有改動「一」。
  - 「收起來」標成 ㄕㄡ ㄑㄧˇ ㄌㄞˊ；如果課本的「來」標輕聲，要改正解。
  - 「收起來」「數一數」是動作，圖片分別畫成「玩具放進箱子」和「手指點數蘋果」。
