- 注音已由 Codex 核對（2026-11-08）：
  - 「一」依翰林課本標變調：數一數 ㄕㄨˇ ㄧˋ ㄕㄨˇ、一張圖 ㄧˋ ㄓㄤ ㄊㄨˊ。錯誤選項也用 ㄧˋ，只改要練的那個音。
