## 著作權與收錄原則

課文全文屬出版社教材著作權；本目錄不轉錄全文。日後若要建立 WordFlash 字庫，應以：

- 使用者提供的課本照片、老師指定的字詞或可授權素材為依據；
- 每一課建立「生字、詞語、注音、來源頁碼」等練習資料；
- 將來源、版本及建立日期寫回本資料夾，避免與其他版本混用。
