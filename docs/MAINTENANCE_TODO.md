# WordFlash 維護待辦

最後整理：2026-10-24。此文件是專案擁有者的決策與維護清單，不代表每個項目都必須開發。

目前正式基準為 **v1.0.0**。專案功能已接近完成，原則是只做能改善實際親子使用情境的變更。

## 先確認的事項

### P1：跨裝置練習紀錄

**現況**：多字庫選擇、各字庫的字詞啟用狀態、個別字詞正確率、統計模式的答對／答錯、不限時挑戰連勝、計時挑戰設定／進行狀態，以及挑戰紀錄都只存於本機瀏覽器。Google 登入目前只同步字庫；切換帳號不會隔離本機單字紀錄。

**使用者期待**：同一帳號換手機、平板或電腦後，能延續練習進度。

**開工前需決定**：

- 要同步統計模式、不限時挑戰、已完成的計時挑戰紀錄，還是其中一部分？進行中的倒數是否應跨裝置延續？
- 統計資料與挑戰紀錄要永久累積、按字庫分開，還是能手動開始新一輪？
- 兩台裝置同時練習時，以最後寫入為準，還是做累計合併？
- 切換 Google 帳號後，本機舊進度要保留、覆蓋，還是詢問使用者？

**建議的最小版本**：Firebase 每個帳號新增獨立的 `practiceSession` 與 `challengeRecords` 路徑，先只同步已完成的資料並採「最後一次儲存覆蓋」；字庫與練習紀錄分開存放，不連同字庫下載／上傳操作一起覆蓋。進行中的倒數應先維持本機，避免兩台裝置同時結束同一輪造成不清楚的結果。

### P1：字庫同步的覆蓋規則

**現況**：字庫管理頁儲存後會自動同步；顯示頁與字庫管理頁登入後會嘗試載入雲端字庫；設定頁仍提供明確的上傳／下載按鈕。設定頁切換目前字庫時，登入狀態下也會寫入雲端。

**風險**：不同裝置各有版本時，使用者不容易知道哪一份會成為最新版。

**建議**：下次修改雲端同步前，統一為下列其中一種策略：

1. 登入後以雲端為主，本機資料只在首次上傳時使用。
2. 每次遇到不同版本都要求選擇「保留本機」或「使用雲端」。
3. 建立可理解的合併規則並顯示最後更新時間。

對目前個人使用情境，選項 2 最不容易意外覆蓋資料。

## 小型維護項目

### P2：提供給一般使用者時，改用單層字庫目錄

**現況**：字庫管理的試用介面已驗證多層資料夾、收合、拖曳與就地新增資料夾可行；功能完整，但操作概念較多。

**方向**：若日後要讓非專案擁有者使用，優先提供或改為**單層目錄**：每個字庫只歸屬一個最外層分類，不再出現巢狀資料夾、收合箭頭或跨層移動。未分類字庫仍保留在預設分類中。

**原因**：一般家長較容易理解「分類 → 字庫」兩層結構，也可避免誤把字庫移入不易找到的子資料夾。現有多層目錄試作可保留作為進階方案或開發參考，不需要現在回改正式字庫資料。

### P2：統一字型預設值

顯示頁沒有設定時使用的預設字型，與設定頁快速切換顯示的第一個預設選項不同。下一次修改字型時，應抽出共同常數或至少讓兩者預設值一致。

### P2：增加同步狀態提示

可在設定頁清楚顯示：最後同步時間、目前字庫是否只在本機、以及上一次同步是否失敗。這比增加更多功能更能降低資料遺失疑慮。

### P3：大量字庫的注音查詢保護

目前一次儲存會同時向萌典查詢多筆資料。若未來需要匯入大量字表，可加入分批查詢、進度文字與逾時提示；目前一般小字庫不需要先做。

### P3：補充使用文件圖片

若要給其他家長使用，可在 `docs/USER_GUIDE.md` 加上設定頁、字庫管理與多音字選擇的截圖。現階段文字說明已足夠。

## 已完成，不需重做

- 手機直式與 iPad 橫式採不同版面設計。
- 手機按鈕尺寸已調整。
- 注音可開關，並以右側直式方式對齊字元。
- 多音字以完整詞語優先查詢；無法判定時由使用者選擇。
- 設定頁已依高頻到低頻排序：快速切換、練習、顯示、工具列、字庫管理、帳號同步。
- 顯示頁不放帳號按鈕；登入、切換帳號及字庫同步都在設定頁。
- 挑戰積木使用書背式排列，會依寬度自動換列；三層一般書架滿後改用半尺寸緊密書架，約可容納四倍數量並防止超出畫面。
- 挑戰模式可設定 10–3,600 秒倒數；時間到保存本輪最佳連勝，並可在挑戰紀錄頁依字庫查看或刪除本機紀錄。
- Google 登入、切換帳號與個人雲端字庫已完成。
- 可混合選擇多個字庫、逐字啟用／停用、查看個別正確率，挑戰模式可加強不熟字詞；新增資料仍只存在本機。
- Pixel 10a 與 iPad 橫向的 Playwright 基本測試已建立。

## 每次修改前

- [ ] 先確認這是實際使用需求，而非只為了技術上的整潔。
- [ ] 不影響既有字庫的 `文字|注音` 格式。
- [ ] 若涉及本機或雲端資料，先寫出覆蓋與復原方式。
- [ ] 若涉及畫面，至少確認手機直式與 iPad 橫式。
- [ ] 若涉及注音，使用含多音字的詞語人工驗證。
