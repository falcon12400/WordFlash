# WordFlash
WordFlash 是一個輕量的字卡練習網頁，支援多單元字庫與字型切換，適合中文或英文單字練習。

## 主要頁面

- `index.html`
  - 專案入口頁，會自動跳轉到 `canvas_words.html`

- `canvas_words.html`
  - 大字顯示頁
  - 用來給小朋友練習看字、翻字卡、切換字庫與字型

- `manage_words.html`
  - 字庫管理頁
  - 用來編輯或整理字庫內容
